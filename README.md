# My3dModels

**In progress.** About thirty 3D-printable models designed in Blender: math and art shapes, nature, small
mechanisms and useful things for the desk. Each model will come with STL/3MF, the Blender source, a render and
tested print settings.

## Status

The models exist and were printed on an Elegoo Centauri Carbon (0.4 mm nozzle). Now each one is being checked
(size, printability, no third-party logos), rendered and described. Folders appear here as models are ready.

## What will be here

- **Math and art:** gyroid cube, trefoil knot, Penrose triangle, hyperboloid tower, DNA helix, fractal tree,
  nautilus, twisted vase, rosette panel, dual-shadow sculpture, interference pattern, infinite zoom cubes.
- **Nature:** coral, crystal druse, pinecone, snowflake, sunflower disc.
- **Mechanisms:** planetary gears, wave machine, pea-less whistle, cube slot drop.
- **Useful:** nuts and bolts set, cord stopper, headphone stands, fairy house, small house, Eiffel tower.
- **Test set for print monitoring AI:** eight small models, each made to fail in one known way (spaghetti,
  detachment, under-extrusion, stringing, warping) - for training a camera that watches the print.

## Each model folder

- `model.stl` (and `.3mf` where useful), `model.blend` - the source;
- `render.png`;
- `README.md` with print settings: nozzle, layer height, supports, infill, material, time and weight.
