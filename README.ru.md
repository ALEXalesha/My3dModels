# My3dModels

**В работе.** Около тридцати моделей для 3D-печати, сделанных в Blender: математические и художественные
формы, природа, маленькие механизмы и полезные вещи для стола. У каждой модели будут STL/3MF, исходник Blender,
рендер и проверенные настройки печати.

## Состояние

Модели уже есть и печатались на Elegoo Centauri Carbon (сопло 0.4 мм). Сейчас каждую проверяем (размер,
печатаемость, нет ли чужих логотипов), рендерим и описываем. Папки появляются здесь по мере готовности.

## Что здесь будет

- **Математика и искусство:** гироидный куб, узел-трилистник, треугольник Пенроуза, гиперболоидная башня,
  спираль ДНК, фрактальное дерево, наутилус, закрученная ваза, панель-розетка, скульптура с двумя тенями,
  интерференция, бесконечные кубы.
- **Природа:** коралл, друза кристаллов, шишка, снежинка, диск подсолнуха.
- **Механизмы:** планетарная передача, волновая машина, свисток без шарика, куб с прорезью.
- **Полезное:** набор гаек и болтов, фиксатор шнура, подставки для наушников, домик феи, домик, Эйфелева башня.
- **Тестовый набор для ИИ, который следит за печатью:** восемь маленьких моделей, каждая ломается одним
  известным способом (спагетти, отрыв, недоэкструзия, паутина, коробление) - для обучения камеры.

## Что в папке каждой модели

- `model.stl` (и `.3mf`, где нужно), `model.blend` - исходник;
- `render.png`;
- `README.md` с настройками печати: сопло, слой, поддержки, заполнение, пластик, время и вес.
